# 验证记录

## 已证实

- 增量安装曾导致系统模块开机不可读：Vector 报无法打开 APK，APK 实际位于 incremental-fs。完整安装到 f2fs 并核对注册后，system_server 已加载系统模块。
- 同一把小米键盘的蓝牙、Pogo 两种接口都存在。Fn 与顶排之间有短暂 Ctrl Up / Down 序列；1.7 依据这段序列增加有限桥接。
- 0.2.0 Mac 统一 App 实际收到过 Launchpad 动作；它在组合键 Down 时立即执行，用户反馈会进入图标编辑模式。0.2.1 改为修饰键释放后的 Up 提交。
- 构建检查覆盖修饰映射、Fn 生命周期和释放帧、普通键重复、双指/三指状态、来源过滤、Mac 控制提交/取消；APK 和 Mac 签名检查通过。
- 新部署脚本已实机执行，完整安装和 Vector 注册路径检查通过；不恢复或改写整个 Vector 数据库。

## 尚未通过实机验收
