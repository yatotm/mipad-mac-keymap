# 验证记录

## 历史结果与故障根因

- 系统模块的增量安装曾使开机加载失败。完整安装到 f2fs 并核对注册后，system_server 已加载 1.7；用户已确认 Fn 音量、亮度生效。
- Fn 顶排存在很短的释放帧；1.7 通过有限时间桥接处理，同一键盘的蓝牙/Pogo 共用 Fn 状态。
- 0.2.1 曾消除 Launchpad 图标编辑模式，用户已确认。
- 0.10.2 的双指左右导航已收到用户“正常”反馈，但之后出现 Option 粘住；纵向滚动又偏快。
- 旧协议占用 Control＋Option＋Command＋空格，确实会截走用户四分屏快捷键。这不是用户配置问题。0.3.0 已删除整个键盘事件拦截器和旧控制组合协议。
- 滚轮临时采样发现 UU 事件带 Option/Command 位；这批事件在 Mos 前后的像素位移一致，没有看到 Mos 二次增大。不能将该次异常直接归因于 Mos。

## 0.11.0 / Helper 0.3.0 已验证

- Android 编译、108 项输入边界检查、双指方向状态检查和 APK 签名校验通过；完整安装与 Vector 当前 APK 注册检查通过。
- Mac 检查覆盖固定动作白名单、非法/越界帧、先握手再执行、过期/倒序丢弃、修饰位转换、像素位移和接触/惯性阶段。检查不发送实际输入事件。
- FIFO 为应用私有目录中的 0600 管道；连续收到 hello/sync。竞争读取端取锁失败，未分食输入事件。
- Mac 实际连接代码已收到连续心跳，时钟检查无拒绝。旧 Android mksh 文件描述符未传给子进程的问题已实测修正。
- 已安装并完成新版辅助功能授权。运行状态为 connected、permission=true、keyboard_tap=false、scroll_tap=true。
- 通过 CGGetEventTapList 核对实际运行进程只有滚轮掩码 4194304，无键盘 tap。只运行一个 Pad Mac Helper。
- 已经收到实体滚动及一次横向动作，不据此推断浏览器已正确导航。
- 纵向参数仍为 scroll_scale=0.25、inertia_strength=4；Mos 保持原设置；平板 trace 已关闭。

## 支持边界

已验证的原生事件是像素滚动及其阶段，并非完整多点 HID 触控板。三指部分系统导航仍用 Mac 系统快捷入口。跨网段、Tailscale 入站转发与完整虚拟多点设备尚未验证。

## 0.11.0 实体验收失败与 0.11.1 恢复

用户明确反馈：上下和左右滚动、Fn、三指下滑和左右切屏失效；只有捏合 Launchpad 和三指上滑生效。此前的构建、心跳、接收计数不能作为这些功能通过的证据。

检查结果：

- 失败期间 Mac 收到 914 条滚动、导航动作，但没有 Fn 动作。接收与实际执行是不同边界，Fn 还须独立定位。
- macOS TCC 日志中该 Helper 的 ListenEvent、Accessibility、PostEvent 均为允许，不能断言只是未授权。
- Helper 重启曾残留旧 ADB 读取进程，持锁阻止新读取端；已终止该残留，安装脚本增加精确清理。
- 后续受控采样见到了 Helper 生成的滚动事件进入系统；这不证明它们送达了平板正在操作的目标。原生路径的窗口/屏幕目标和实际效果仍未查清。
- 0.11.1 恢复 UU 滚动与方向快捷操作；Fn 拦截提前到实际 ScreenActivity 的 dispatchKeyEvent。捏合/上滑保留已生效的系统应用入口。
- 0.11.1 编译、108 项输入边界检查、双指方向检查、签名、完整安装/Vector 注册和运行加载通过。**尚未收到 0.11.1 的实体恢复确认。**

两次限时 Fn 原始采样没有收到目标按键，不能据此推断键盘不上报 Fn，也不能确认 Fn 问题已经修复。当前待测：上下滚动、Chrome 左右、三指下/左右、Fn 音量以及四分屏组合。

## 1.8 / 0.11.2 Fn 验收（2026-09-26）

用户先确认 0.11.1 除 Fn 外基本正常，随后进行了单按顶排和按住 Fn 的三轮对照。完整报告确认 `0xEA`、`0x70` Consumer 用途被表现为键盘修饰位图，原来的功能键识别路径无法命中。

- 新增 238 项蓝牙 Fn 位图/释放状态检查，包括按住重复、同键再次触发、释放过程中不反向触发、失焦取消和普通修饰键直通。
- 原有 18 项 HeldFn、10 项 Fn/Control、路由/去重/修饰映射、108 项 UU 输入边界检查及双指检查通过。
- 本机功能消息的 UID、版本、时效、前台条件、编号范围检查通过。
- 系统 1.8 与 UU 0.11.2 完整安装；Vector 实际在 system_server 中加载系统模块；UU 运行日志确认新版本。
- 实机记录出现系统发送、UU 接收和 Mac 接收/执行三个阶段。Mac 记录到亮度减 28、亮度加 12、音量减 9、音量加 7、静音 3 次请求；这些计数含用户重复按键/按住操作，不代表逐键覆盖了全部 F1–F12。
- 用户明确反馈：**“测试Fn键生效”**。此次 Fn 修复通过用户验收。

没有自动触发睡眠，也没有宣称截图、Siri、全部媒体键、Pogo 模式或额外 Fn 修饰组合都已逐项实测。Mac Helper 未更换，滚动和手势代码保持恢复版；未修改 Codex 或终端设置。

本轮临时采样已停止，原始采样仅提炼为以上结论后清理。框架可能产生默认用户广播的常规 ContextImpl 警告；没有为此新增日志文件或再次更换已验收的运行版本，后续维护可改用显式用户的系统广播接口。
