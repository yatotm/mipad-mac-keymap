# 验证记录

## 历史结果与故障根因

- 系统模块的增量安装曾使开机加载失败。完整安装到 f2fs 并核对注册后，system_server 已加载 1.7；用户已确认 Fn 音量、亮度生效。
- Fn 顶排存在很短的释放帧；1.7 通过有限时间桥接处理，同一键盘的蓝牙/Pogo 共用 Fn 状态。
- 0.2.1 曾消除 Launchpad 图标编辑模式，用户已确认。
- 0.10.2 的双指左右导航已收到用户“正常”反馈，但之后出现 Option 粘住；纵向滚动又偏快。
- 旧协议占用 Control＋Option＋Command＋空格，确实会截走用户四分屏快捷键。这不是用户配置问题。0.3.0 已删除整个键盘事件拦截器和旧控制组合协议。
- 滚轮临时采样发现 UU 事件带 Option/Command 位；这批事件在 Mos 前后的像素位移一致，没有看到 Mos 二次增大。不能将该次异常直接归因于 Mos。

## 0.11.0 / Helper 0.3.0 已验证

- Android 编译、108 项输入边界检查、双指方向状态检查和 APK 签名校验通过；完整安装与 Vector 当前 APK 注册检查通过。
- Mac 检查覆盖固定动作白名单、非法/越界帧、先握手再执行、过期/倒序丢弃、修饰位转换、像素位移和接触/惯性阶段。检查不发送实际输入事件。
- FIFO 为应用私有目录中的 0600 管道；连续收到 hello/sync。竞争读取端取锁失败，未分食输入事件。
- Mac 实际连接代码已收到连续心跳，时钟检查无拒绝。旧 Android mksh 文件描述符未传给子进程的问题已实测修正。
- 已安装并完成新版辅助功能授权。运行状态为 connected、permission=true、keyboard_tap=false、scroll_tap=true。
- 通过 CGGetEventTapList 核对实际运行进程只有滚轮掩码 4194304，无键盘 tap。只运行一个 Pad Mac Helper。
- 已经收到实体滚动及一次横向动作，不据此推断浏览器已正确导航。
- 纵向参数仍为 scroll_scale=0.25、inertia_strength=4；Mos 保持原设置；平板 trace 已关闭。
