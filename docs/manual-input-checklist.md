# Moonlight 手动测试清单

本轮环境：系统键盘 1.9、Moonlight 输入模块 0.2.6、Pad Mac Helper 0.5.4、官方 Moonlight 12.2、Sunshine 2026.914.233613 + Pad 光标补丁 1。旧 UU 路径保留，本轮优先验收 Moonlight。

当前已收到鼠标、手势和重新授权后键盘正常的反馈。以下为后续版本回归清单。先用单指移动触控板：箭头应跟手、停手即停且只有一个。虚拟屏时点安全空白位置，确认点位仍准确。

打开平板上的**官方 Moonlight → Chenxi Mac → Desktop**。无需打开测试窗口或启动监听器。Mac 保留原来的 Mos 和 BetterDisplay 配置。左右切换桌面前，被控制的那块显示器必须有至少两个桌面；检查时虚拟显示器只有一个桌面。

| 顺序 | 操作 | 预期与观察重点 |
| --- | --- | --- |
| 1 | Chrome 打开网页，再点击链接进入下一页，双指向右/向左滑动；鼠标放在一条可丢弃通知上，双指右滑 | 浏览器后退/前进、通知滑走。Chrome 已确认生效；0.5.4 横向比例和通知滑动已收到“目前触控手势正常”反馈；后续回归时复核。Launchpad 横滑中途停住 1 秒、反向，页面应跟随 |
| 2 | 双指落下立即纵向滑动，再快速甩动并抬手，最后轻触 | 起步及时、方向和速度合适；快滑惯性更大，重新落指停止；连续操作后 Option 不应卡住 |
| 3 | 三指直接上、下、左、右滑；左右滑到一半停 1–2 秒，再反向；动画未结束时重新起手 | 上滑所有窗口、下滑当前应用窗口、左右切桌面；画面能跟随、停住、反向、中途接管 |
| 4 | 三指停约 0.3 秒再移动窗口标题栏，抬手；另做三指收拢、双指捏合 | 停留后拖拽，抬手立即释放；三指收拢打开 Launchpad，不出现图标抖动；双指捏合在支持的应用内缩放 |
| 5 | 长按字母、方向键、Backspace；测试 Option＋↑、Control＋Option＋Command＋空格；按住 Fn 后按顶排 | 长按持续输入/移动/删除；原应用组合键生效；裸顶排为 F1–F12，Fn 组合控制 Mac。先测亮度、音量、静音，睡眠留到最后 |
| 6 | 退出再进入 Moonlight；蓝牙与触点连接各复测修饰键、Fn、滚动和三指；最后试四指 | 退出后平板原操作恢复，重连无残留按键。四指是否能被固件实际报告仍待确认 |

实体键位：最左下原 Ctrl＝**按住式 Fn**，语音键＝**Control**，四叶草＝**Option**，Alt＝**Command**。Fn 用于本适配的功能层，不应弹出 Mac 地球键菜单。

自动回放已经确认长按和修饰位、Fn 音量、滚动阶段、拖拽释放，以及 Mac 切屏后端的半程保持和中断。它不能替代真实手感验收；Chrome 和 Launchpad 已有用户成功反馈；0.5.4 当前触控手势已收到用户正常反馈，指针单独验收。

反馈可直接写：`序号 / 蓝牙或触点 / 应用 / 实际现象`。例如：`1 / 蓝牙 / Chrome / 双指右滑没有反应，纵向滚动正常`。

0.2.6 新增回归：双指轻触并全部抬起应右击，滚动/捏合后抬手不应弹菜单；光标为原尺寸的 65%。用户已确认右击与大小正常。持续移动时同时按键在蓝牙模式正常；触点模式有松键后约 0.5 秒的底层暂停，见 [已知问题](keyboard-pointer-concurrency.md)。
